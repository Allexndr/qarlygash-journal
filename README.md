# Қарлығаш - Психологический журнал

Информационный портал для публикации научных статей, обзоров и отчетов о фундаментальных и прикладных исследованиях в области психологии подростков и кризисной психологии.

## Технологии

- **Next.js 14** - React фреймворк с App Router
- **TypeScript** - Типизация
- **Tailwind CSS** - Стилизация
- **MongoDB** - База данных
- **React Quill** - Редактор контента
- **Framer Motion** - Анимации (опционально)

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env.local` на основе `.env.local.example`:
```bash
cp .env.local.example .env.local
```

3. Заполните переменные окружения в `.env.local`:
   - `MONGODB_URI` - URI подключения к MongoDB Atlas
   - `NEXT_PUBLIC_SITE_URL` - URL вашего сайта

4. Запустите dev сервер:
```bash
npm run dev
```

5. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## SEO Оптимизация

Проект включает полную SEO оптимизацию:

1. **Мета-теги**: Автоматическая генерация для каждой страницы
2. **Open Graph**: Для социальных сетей
3. **Twitter Cards**: Для Twitter
4. **Structured Data (JSON-LD)**: Schema.org разметка для статей
5. **Sitemap.xml**: Автоматическая генерация карты сайта
6. **Robots.txt**: Управление индексацией
7. **Canonical URLs**: Предотвращение дублей контента

## MongoDB Структура

### Коллекции:
- `articles` - Статьи
- `authors` - Авторы
- `pages` - Статические страницы
- `siteSettings` - Настройки сайта
- `teamMembers` - Участники команды
- `tools` - Инструменты самопомощи

## API Endpoints

- `GET /api/articles` - Получить все статьи
- `POST /api/articles` - Создать статью
- `GET /api/articles/[id]` - Получить статью
- `PATCH /api/articles/[id]` - Обновить статью
- `DELETE /api/articles/[id]` - Удалить статью
- `GET /api/authors` - Получить всех авторов
- `POST /api/authors` - Создать автора
- `GET /api/site-settings` - Получить настройки
- `PATCH /api/site-settings` - Обновить настройки
- `GET /api/team` - Получить команду
- `POST /api/team` - Добавить участника
- `GET /api/tools` - Получить инструменты
- `POST /api/tools` - Создать инструмент

## Развертывание на Vercel

1. Подключите репозиторий к Vercel
2. Добавьте переменные окружения в настройках проекта:
   - `MONGODB_URI`
   - `NEXT_PUBLIC_SITE_URL`
3. Деплой произойдет автоматически
